## crear y activar entornos en python:
crear un entorno:
```python
python -m venv <nombre-entorno>
```

Activar un entorno:
```python
# windows
<nombre-entorno>\Scripts\activate

#Unix
source <nombre-entorno>/bin/activate
```

Desactivar un entorno:
```python
deactivate
```
